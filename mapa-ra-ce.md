# Mapa RA – CE — Programación (0485)

Relación entre las 14 unidades, las 9 RA y los 79 criterios de evaluación del módulo (RD 405/2023). Cada CE aparece asignado a una única unidad como referencia principal.

## U01. Introducción a la algorítmica y pseudocódigo — RA1
- a) Identificado los bloques que componen la estructura de un programa informático.
- b) Creado proyectos de desarrollo de aplicaciones.
- c) Utilizado entornos integrados de desarrollo.

## U02. Primeros pasos en Java: sintaxis y tipos de datos — RA1, RA2
**RA1**
- d) Identificado los distintos tipos de variables y la utilidad específica de cada uno.
- e) Modificado el código de un programa para crear y utilizar variables.
- f) Creado y utilizado constantes y literales.
- g) Clasificado, reconocido y utilizado en expresiones los operadores del lenguaje.
- h) Comprobado el funcionamiento de las conversiones de tipo explícitas e implícitas.
- i) Introducido comentarios en el código.

**RA2**
- c) Instanciado objetos a partir de clases predefinidas.
- i) Utilizado el entorno integrado de desarrollo en la creación y compilación de programas simples.

## U03. Estructuras de control de flujo y excepciones — RA3
- a) Escrito y probado código que haga uso de estructuras de selección.
- b) Utilizado estructuras de repetición.
- c) Reconocido las posibilidades de las sentencias de salto.
- d) Escrito código utilizando control de excepciones.
- f) Probado y depurado los programas.
- g) Comentado y documentado el código.

## U04. Métodos y recursividad — RA2, RA3
**RA2**
- e) Escrito llamadas a métodos estáticos.
- f) Utilizado parámetros en la llamada a métodos.

**RA3**
- e) Creado programas ejecutables utilizando diferentes estructuras de control.
- h) Creado excepciones.
- i) Utilizado aserciones para la detección y corrección de errores durante la fase de desarrollo.

## U05. Programación orientada a objetos: clases y objetos — RA2, RA4
**RA2**
- a) Identificado los fundamentos de la programación orientada a objetos.
- b) Escrito programas simples.
- d) Utilizado métodos y propiedades de los objetos.
- g) Incorporado y utilizado librerías de objetos.
- h) Utilizado constructores.

**RA4**
- a) Reconocido la sintaxis, estructura y componentes típicos de una clase.
- b) Definido clases.
- c) Definido propiedades y métodos.
- d) Creado constructores.
- e) Desarrollado programas que instancien y utilicen objetos de las clases creadas anteriormente.

## U06. Encapsulación, visibilidad y miembros static — RA4
- f) Utilizado mecanismos para controlar la visibilidad de las clases y de sus miembros.
- h) Creado y utilizado métodos estáticos.
- i) Creado y utilizado conjuntos y librerías de clases.

## U07. Herencia, polimorfismo e interfaces — RA4, RA7
**RA4**
- g) Definido y utilizado clases heredadas.

**RA7**
- a) Identificado los conceptos de herencia, superclase y subclase.
- b) Utilizado modificadores para bloquear y forzar la herencia de clases y métodos.
- c) Reconocido la incidencia de los constructores en la herencia.
- d) Creado clases heredadas que sobrescriben la implementación de métodos de la superclase.
- e) Diseñado y aplicado jerarquías de clases.
- f) Probado y depurado las jerarquías de clases.
- g) Realizado programas que implementen y utilicen jerarquías de clases.
- h) Comentado y documentado el código.
- i) Identificado y evaluado los escenarios de uso de interfaces.
- j) Identificado y evaluado los escenarios de utilización de la herencia y la composición.

## U08. Arrays y colecciones lineales — RA6
- a) Escrito programas que utilicen matrices (arrays).
- b) Reconocido las librerías de clases relacionadas con tipos de datos avanzados.
- c) Utilizado listas para almacenar y procesar información.
- d) Utilizado iteradores para recorrer los elementos de las listas.

## U09. Genéricos y mapas — RA6
- e) Reconocido las características y ventajas de cada una de las colecciones de datos disponibles.
- f) Creado clases y métodos genéricos.

## U10. Programación funcional y la API Streams — RA6
- j) Utilizado operaciones agregadas para el manejo de información almacenada en colecciones.

## U11. Consola, ficheros, directorios y expresiones regulares — RA5, RA6
**RA5**
- a) Utilizado la consola para realizar operaciones de entrada y salida de información.
- b) Aplicado formatos en la visualización de la información.
- c) Reconocido las posibilidades de entrada/salida del lenguaje y las librerías asociadas.
- d) Utilizado ficheros para almacenar y recuperar información.
- e) Creado programas que utilicen diversos métodos de acceso al contenido de los ficheros.

**RA6**
- g) Utilizado expresiones regulares en la búsqueda de patrones en cadenas de texto.
- h) Identificado las clases relacionadas con el tratamiento de documentos escritos en diferentes lenguajes de intercambio de datos.
- i) Realizado programas que realicen manipulaciones sobre documentos escritos en diferentes lenguajes de intercambio de datos.

## U12. Programación por eventos y GUI (Swing/AWT) — RA5
- f) Utilizado las herramientas del entorno de desarrollo para crear interfaces gráficos de usuario simples.
- g) Programado controladores de eventos.
- h) Escrito programas que utilicen interfaces gráficos para la entrada y salida de información.

## U13. JDBC, persistencia de objetos y NoSQL — RA8, RA9
**RA8**
- a) Identificado las características de las bases de datos orientadas a objetos.
- b) Analizado su aplicación en el desarrollo de aplicaciones mediante lenguajes orientados a objetos.
- c) Instalado sistemas gestores de bases de datos orientados a objetos.
- d) Clasificado y analizado los distintos métodos soportados por los sistemas gestores para la gestión de la información almacenada.
- e) Creado bases de datos y las estructuras necesarias para el almacenamiento de objetos.
- f) Programado aplicaciones que almacenen objetos en las bases de datos creadas.
- g) Realizado programas para recuperar, actualizar y eliminar objetos de las bases de datos.
- h) Realizado programas para almacenar y gestionar tipos de datos estructurados, compuestos y relacionados.

**RA9**
- a) Identificado las características y métodos de acceso a sistemas gestores de bases de datos.
- b) Programado conexiones con bases de datos.
- c) Escrito código para almacenar información en bases de datos.
- d) Creado programas para recuperar y mostrar información almacenada en bases de datos.
- e) Efectuado borrados y modificaciones sobre la información almacenada.
- f) Creado aplicaciones que muestren la información almacenada en bases de datos.

> NoSQL no tiene CE propio en 0485 — se trata como contenido de ampliación, sin RA/CE oficial que lo respalde.

## U14. Proyecto final integrador — RA9 (+ consolidación RA5, RA6)
**RA9**
- g) Creado aplicaciones para gestionar la información presente en bases de datos.

Consolida CE de RA5 y RA6 ya trabajados en unidades anteriores; no introduce CE nuevos.

**Cobertura verificada:** 79/79 criterios de evaluación de las 9 RA quedan asignados a exactamente una unidad como responsable principal. Ninguno queda huérfano.
