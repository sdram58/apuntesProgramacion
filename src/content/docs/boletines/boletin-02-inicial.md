# 📝 Boletín U02 — Inicial

Ejercicios de Java real. Escríbelos y pruébalos en IntelliJ IDEA antes de mirar la solución.

1. Escribe un programa Java que declare una variable `int` con tu edad y una variable `String` con tu nombre, y muestre por pantalla "Me llamo X y tengo Y años".

2. ¿Cuál es el tipo de dato más adecuado para cada uno de estos datos, y por qué: el número de habitantes de España, el precio de un producto con decimales, si un usuario está o no registrado, la letra inicial de un DNI?

3. Declara una constante `IVA` con el valor `0.21` y escribe un programa que pida un precio sin IVA y muestre el precio final con IVA aplicado.

4. ¿Qué muestra por pantalla este código, y por qué? `System.out.println(7 / 2); System.out.println(7.0 / 2);`

5. Escribe un programa que declare dos variables `int`, `a` y `b`, y muestre su suma, resta, producto, división entera y resto (`%`).

6. Usa `Math.pow` y `Math.sqrt` para escribir un programa que, dado el valor de un cateto de un triángulo rectángulo isósceles, calcule la hipotenusa (pista: teorema de Pitágoras).

7. Declara un `String` con tu nombre completo y usa sus métodos para mostrar: su longitud, en mayúsculas, y solo los 3 primeros caracteres.

8. Explica con tus propias palabras la diferencia entre conversión implícita y casting explícito, y pon un ejemplo de cada una en Java.
