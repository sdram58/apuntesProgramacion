# 📝 Boletín U01 — Inicial

> Sin soluciones. Sin prisas. Con papel y lápiz — todavía no hace falta abrir IntelliJ.

---

## Ejercicio 1: ordena la receta

Estos pasos para preparar un café con leche están desordenados. Numéralos del 1 al 5 para formar un algoritmo válido.

```
- Servir el café en la taza.
- Añadir la leche caliente.
- Calentar la leche.
- Poner la cafetera en el fuego.
- Esperar a que salga el café.
```

---

## Ejercicio 2: ¿cumple las cinco propiedades?

Para cada "algoritmo", indica si cumple las cinco propiedades (finito, preciso, con entrada, con salida, eficaz) y, si no, cuál falla:

a) "Repite: suma 1 a un contador. No pares nunca."
b) "Lee un número. Si es mayor que 10, escribe 'grande'. Si no, escribe 'pequeño'."
c) "Cocina la pasta el tiempo que veas."
d) "Lee dos números. Calcula y escribe su suma."

## Ejercicio 3: traza a mano

Traza este pseudocódigo para `edad = 15` y para `edad = 20`. Escribe exactamente lo que muestra `ESCRIBIR` en cada caso.

```
INICIO
  LEER edad
  SI edad >= 18 ENTONCES
    ESCRIBIR "Eres mayor de edad"
  SINO
    ESCRIBIR "Eres menor de edad"
  FINSI
FIN
```

## Ejercicio 4: identifica el bloque

Para cada fragmento de pseudocódigo, indica si es **secuencia**, **selección** o **iteración**:

a)
```
LEER a
LEER b
ESCRIBIR a + b
```

b)
```
MIENTRAS contador < 10 HACER
  contador ← contador + 1
FINMIENTRAS
```

c)
```
SI nota >= 5 ENTONCES
  ESCRIBIR "Aprobado"
FINSI
```

## Ejercicio 5: completa el pseudocódigo

Falta una línea en este algoritmo que debería mostrar si un número es positivo o negativo. Añádela donde corresponda.

```
INICIO
  LEER numero
  SI numero >= 0 ENTONCES
    ESCRIBIR "Positivo"
  SINO

  FINSI
FIN
```

## Ejercicio 6: empareja conceptos

Relaciona cada concepto de la izquierda con su definición de la derecha:

| Concepto | Definición |
|---|---|
| 1. Algoritmo | A. Representación gráfica con símbolos y flechas |
| 2. Pseudocódigo | B. Secuencia finita y precisa de pasos que resuelve un problema |
| 3. Diagrama de flujo | C. Carpeta con el código y la configuración que usa el IDE |
| 4. Proyecto | D. Escritura de un algoritmo sin sintaxis de un lenguaje concreto |

Escribe las respuestas como "1→B, 2→D, ...".

## Ejercicio 8: caza la ambigüedad

Cada uno de estos pasos es ambiguo y no serviría dentro de un algoritmo preciso. Reescribe cada uno para que no deje lugar a interpretación:

a) "Añade sal al gusto."
b) "Espera un rato."
c) "Si el número es grande, avisa."
